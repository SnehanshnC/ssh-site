# Content pack

The YAML files in this directory are fetched artifacts from [github.com/SnehanshnC/content-pack](https://github.com/SnehanshnC/content-pack), pulled down by `make content` (which runs `scripts/fetch-pack.sh`).
They are refreshed from that source on every fetch and are never edited here - this README is the only file in this directory that is tracked in git.
